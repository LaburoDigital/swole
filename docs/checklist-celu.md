# Checklist en celu real — Etapa 1

Versión a probar: **v83** · https://laburodigital.github.io/swole/
Tiempo: ~20 min por celu. Marcá cada ítem con ✓ (anda) o ✗ (falla) y, si falla, una línea de qué pasó + captura.

**Antes de empezar (en cada celu):**
- Anotá: modelo del celu, sistema (Android 14, iOS 18…) y navegador.
- Abrí el link con datos o Wi‑Fi de casa (en el Wi‑Fi del colegio GitHub está bloqueado y ves una versión vieja).
- En Perfil (avatar arriba) fijate que diga v83. Si dice otra, cerrá y abrí de nuevo.
- Usá **tu cuenta en los dos celus** (hace falta para el ítem 10).
